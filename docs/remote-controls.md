# Remote controls

Designed for a basic Android TV remote: D-pad, OK, Back, Home, volume. No number or channel keys
needed.

| Screen | Controls |
|---|---|
| **Home** | D-pad to move (the page scrolls), OK to open. Home always returns to the top. Pills top-right: HDMI inputs, Wi-Fi, Bluetooth, Sound, Settings. Retro TV's decade tiles open that decade directly. |
| **Retro TV** | ◀ ▶ channel · ▲ ▼ category · OK pause/resume · hold OK (or ☰ menu) guide · Back home |
| **Retro TV guide** | D-pad to choose decade, category or (Science) channel; OK tunes right away; Back closes |
| **Radio – stations** | D-pad + OK to play. The "On air" box opens Now Playing. Back home |
| **Radio – Now Playing** | ◀ ▶ station · OK pause · ▼ stop · Back to stations |
| **World's Windows – browser** | Filters on top (All, Favourites, moods), D-pad + OK to open |
| **World's Windows – view** | ◀ ▶ previous/next window · OK (or ▲ ▼) controls: ♡ Favourite, Sound, Wander (10/30/60 min), Next, All windows · Back closes controls, then returns to the browser |
| **Little Office panel** | D-pad scrolls; Back home |
| **Little Office notice** | OK shows why · any other key dismisses (that key press is used up) |
